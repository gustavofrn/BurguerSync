# BurguerSync

Projeto front-end de página de alimentos, organizado para publicação.

## Estrutura do projeto

- `index.html` — página inicial
- `assets/css/` — estilos
- `assets/js/` — interatividade
- `assets/img/` — imagens

## Execução

Após adicionar os arquivos, abra `index.html` no navegador.

## Aviso sobre o conteúdo

O material de origem usa elementos e referências de **Impossible Foods**. Este projeto não é afiliado à marca. Antes da distribuição pública, verifique os direitos de uso de imagens, identidade visual e demais recursos de terceiros.

> O código e os recursos do arquivo ZIP original ainda precisam ser enviados para completar o repositório. O ZIP organizado foi preparado separadamente.
