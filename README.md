# BurguerSync

**Interface web de apresentação de produtos alimentícios**, desenvolvida com tecnologias front-end e organizada para estudo, personalização e evolução de um projeto de site.

## Sobre o projeto

O BurguerSync reúne uma página web com estrutura HTML, estilos CSS, scripts JavaScript e recursos visuais. A proposta é explorar a construção de uma interface para o segmento alimentício, com foco na organização dos componentes, apresentação de conteúdo e experiência de navegação.

O material original contém referências visuais à marca Impossible Foods. **BurguerSync é o nome deste repositório, não uma marca associada à Impossible Foods.**

## Tecnologias

- **HTML5:** estrutura e conteúdo da página.
- **CSS3:** layout, tipografia e estilos visuais.
- **JavaScript:** comportamento e interações da interface.
- **Imagens e outros recursos estáticos:** composição visual do site.

## Como executar (após o envio do código)

1. Clone o repositório: `git clone https://github.com/gustavofrn/BurguerSync.git`
2. Abra a pasta do projeto.
3. Execute `index.html` no navegador ou utilize a extensão Live Server do VS Code.
